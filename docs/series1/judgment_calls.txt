MG-J7 [NEEDS-CALL, MAJOR] Does the rho=mu_0 derivation itself mix the same
  two regimes (static vs jammed) that MG-J5 did? CONFIRMED (2026-09-04,
  analysis/medium/rho_mu0_regime_consistency_check.py, 6/6 PASS): the
  conflation is in the FORMULA, not just prose. doc_magnetism Section 1.1
  solves the FLUID relation v_p^2=K/rho for rho -- valid only if the shear
  modulus G is exactly zero for the v_p this uses. But this framework
  separately, pervasively asserts G=rho*Rs^2*c^2 != 0 (Poisson ratio, K/G
  ratio, the MG-J5 resolution's own K_jammed). Standard isotropic elasticity
  (derived directly from the Navier-Cauchy equation, not assumed) says: IF
  G!=0, the compression-wave speed is UNCONDITIONALLY v_p^2=(K+4G/3)/rho,
  not v_p^2=K/rho -- confirmed directly (RC2): using rho=mu_0 with the
  asserted G in the correct solid formula does NOT reproduce v_p=c (gives
  3.06e8 m/s, 2.09% too high). So v_p^2=K/rho (hence rho=mu_0 exactly) and
  G!=0 cannot both be true of the same medium state -- the same conflation
  MG-J5 found, relocated.
  UNTANGLED (RC3-RC6): given v_p=c and v_s=Rs*c alone, the solid formula
  pins K/rho exactly but leaves K and rho individually underdetermined by
  one relation -- a third, independent input is needed, and exactly which
  one is NOT forced by the algebra. Two mutually exclusive choices, both
  consistent with G!=0, both reciprocal images of the same (1-4/3*Rs^2)
  factor that produced MG-J5's 4.22%:
