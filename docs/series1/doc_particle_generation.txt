3.1  Derivation

For a photon to nucleate a Hopf winding in the torsion medium, it must
be traveling at the angle theta such that its path "resonates" with the
Jobson cell lattice geometry. This is a Bragg condition:

  BRAGG CONDITION: L_J = lambda_threshold * sin(theta)

where:
  L_J             = alpha * phi * r_p = 9.93e-3 fm  (Jobson cell edge)
  lambda_threshold = hbar_c / (2*m*c^2)             (photon wavelength at threshold)

Solving for theta:
  sin(theta) = L_J / lambda_threshold = L_J * (2*m*c^2) / hbar_c
             = (alpha*phi*r_p) * 2*m / hbar_c
             = alpha*phi * 2*m * r_p / hbar_c

Since r_p = 4*lambda_p = 4*hbar_c/m_p:
  sin(theta) = alpha*phi * 2*m * (4*hbar_c/m_p) / hbar_c
             = 8 * alpha * phi * (m / m_p)

  WINDING ANGLE:  theta(m) = arcsin( 8 * alpha * phi * m / m_p )   [DERIVED]

  Constants: 8 * alpha * phi = 8 * 7.2974e-3 * 1.6180 = 0.09450

For the proton (m = m_p): theta_p = arcsin(8*alpha*phi) = arcsin(0.09450) = 5.421 deg

CROSS-CHECK (torus knot pitch angle):
  The (1,2) Hopf winding on a torus with major radius R = lambda_p, minor
  radius r = L_J has pitch angle:
    arctan(2*L_J / lambda_p) = arctan(2 * 0.00993 / 0.2103) = arctan(0.09449) = 5.40 deg
  This matches theta_p to 4 significant figures. Zero free parameters.

3.3  Physical interpretation

  Small theta (electron, muon): pair production requires a nearly head-on
  photon -- aligned within < 1 deg of the winding axis. The electron's
  winding is so light that only nearly-collinear photons can form it.

  Large theta (tau, proton): pair production allows a wider range of photon
  incidence angles. The tau allows ~10 deg acceptance.

  The progression theta ~ arcsin(m/m_p * 0.0945) shows that heavier particles
  are more easily nucleated (from an angular alignment perspective) but have
  higher energy thresholds (from the Boltzmann perspective).

4.1  Rate formula (essentially derived)

The rate of pair production at temperature T combines:
  (a) Threshold: exp(-2*m*c^2 / kT)             [Boltzmann suppression]
  (b) Solid angle: sin^2(theta) / 4              [angular alignment fraction]
  (c) Photon flux: n_photon(T) * c               [thermal photon density]
  (d) Geometric cross section: pi * lambda_bar^2 [winding capture area]

Schematic rate per unit volume:
  R(m, T) ~ (n_photon * c) * (pi * lambda_bar^2) * sin^2(theta(m)) * exp(-2mc^2/kT)
           = n_photon * c * pi * (hbar_c/(m*c^2))^2 * (8*alpha*phi*m/m_p)^2 * exp(-2mc^2/kT)

The (m^2) from lambda_bar^-2 and (m^2) from sin^2(theta) combine:
  R ~ n_photon * c * pi * (hbar_c)^2 * (8*alpha*phi)^2 / (m_p*c^2)^2 * exp(-2mc^2/kT)

This is MASS-INDEPENDENT in the prefactor (the m^2 from the angle exactly
cancels the m^-2 from the cross section). The only mass dependence is in
the Boltzmann factor exp(-2mc^2/kT).

  MASS-INDEPENDENT PREFACTOR (WA6, confirmed to machine precision):
  The (m^2) from solid angle and (m^-2) from cross section cancel exactly:
    prefactor(e) = prefactor(p) = 3.0995e-04 fm^2   (ratio = 1.0000)
